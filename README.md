# Video Saver

TikTok-Videos ohne Wasserzeichen aufs Handy speichern. Läuft komplett im Browser, kein Server.

Live: https://danielk2212e.github.io/video-saver/

- Link einfügen (auch `vm.tiktok.com`-Kurzlinks), „Video holen“, dann „In Fotos speichern“ oder „Herunterladen“.
- „Zum Home-Bildschirm hinzufügen“ macht daraus eine App. Auf Android taucht sie im Teilen-Menü von TikTok auf.
- Instagram funktioniert im Browser nicht (Instagram blockiert Zugriffe). Dafür gibt es die Handy-App im Repo `jaja`.

Veröffentlicht über GitHub Pages aus dem Branch `gh-pages` (identischer Inhalt wie `main`).
